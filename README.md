# 覇道 — 春秋戦国都市建設シミュレーション

Three.js によるブラウザゲーム。**現在 Phase 4 完了**(軍編成・戦略マップ・戦術バトル・天下統一)。

## 動作確認のしかた

### いちばん簡単な方法
`index.html` をダブルクリックしてブラウザで開く。
Three.js はローカル同梱(`vendor/three.min.js`)なので、ネット接続もサーバも不要。

### 簡易サーバで開く場合
```
cd C:\Users\kazuh\sengoku-game
python -m http.server 8000
```
→ ブラウザで http://localhost:8000

推奨ブラウザ: Chrome / Edge / Firefox(WebGL が動くもの)

## Phase 4 で確認できること

1. **軍編成** — 「軍務」ボタンで兵を徴兵する。兵は民から募るので人口が減り、毎季の俸給(貨幣)と兵糧(あわ)がかかる。最大8部隊
   - 兵種は時代で進化: 戦車・歩兵(春秋前期)→ 弓兵(春秋後期)→ 弩兵(戦国前期)→ 騎兵・衝車・雲梯(戦国後期)
2. **天下図(戦略マップ)** — 軍務パネルに諸国の位置・国力・生死・従属を描いた地図。遠征中は進軍の矢印が出る
3. **出兵と補給** — 部隊を選び相手を決めて出兵。行軍に2季かかり、兵1人あたり あわ1.5 の兵糧が要る。開戦すれば関係は地に落ちる。行軍中なら呼び戻せる
4. **戦術バトル** — 会戦になると3Dの戦場へ:
   - 部隊をクリックで選択 → 地面クリックで移動、敵クリックで攻撃。全軍前進/後退/退却ボタン、Space で一時停止、1/2 で倍速
   - **地形効果**: 丘に立てば守りが堅く、森では矢が通らず戦車・騎兵が鈍る
   - **士気**: 損害がかさむと部隊は崩れて潰走する。味方の潰走は周囲の士気も下げる
   - **兵種相性**: 戦車は平地の歩兵・弓兵に強く、戈の歩兵は車馬に強く、弩は車騎を射抜き、騎兵は弓・弩を蹂躙する
   - **攻城戦**: 敵都には城壁があり、破られるまで守兵は壁に拠って防御1.9倍。衝車・雲梯で壁を壊すか、損害覚悟の力攻めで抜く
   - **防衛戦**: 敵国が侵攻してくることがある(斥候の警報→翌季会戦)。自国の防御(城壁・望楼)が守りを支える
5. **戦後** — 勝てば賠償+名声。敵の国力を削りきれば**併合**(領土と富)か**従属**(毎年の貢納)を選べる。負ければ名声を落とし、防衛戦で敗れれば劫掠される。**守りが薄いまま防衛戦に敗れると落城=ゲームオーバー**(自動保存から再開可)
6. **天下統一** — すべての国を併合または従属させると勝利。軍務パネルに進み(X/9国)が出る
7. **セーブv4** — 常備軍・遠征・従属国も保存される

### まず試す流れ (Phase 4)
1. 「軍務」→ 徴兵で歩兵2〜3隊+戦車1隊を編成(貨幣と青銅が要る)
2. 天下図で国力の低い国 (魯・鄭・宋あたり) を見つけ、部隊全部に印を付けて出兵
3. 2季後に会戦。全軍前進で城壁ぎわまで進め、弓兵がいれば丘に置く
4. 勝ったら「従属させる」→ 毎年の貢ぎ物。国力を削ってもう一度攻めれば「併合」も選べる
5. 関係が敵対(-40以下)の強国がいると攻め込まれることがある。城壁と望楼で防御を25以上にしておくと、負けても落城だけは免れる

## 天地の広さと橋

- **ワールドは 96×96 タイル**(192×192 ワールド単位)。以前の 64×64 から**面積で約2.2倍**に広がり、川はより長く蛇行し、開拓できる土地も増えた。カメラの可動範囲・引きの上限・日射しと影の範囲・霧の距離もマップの広さに合わせて自動で決まる
- **橋(経済タブ)** — 水の上に架けられる唯一の建物。**岸か、すでに架かった橋のとなり**にしか置けないので、岸から一枚ずつ川を渡していく。隣り合う橋と自動でつながり(直線・L字・十字)、つながらない辺には欄干が立つ
  - **ゆるいアーチを描く**: 岸から遠い桁ほど持ち上がり、タイルの境界では隣と高さを半分ずつ分け合うので、段差なくつながった曲線になる。長い橋は中ほどが高く反り、中州に触れるところで一度降りる
  - 手すり・支柱・杭は丸材。両端は**取り付け部が岸へ乗り上げ**、着地点の地面の高さを測ってそこへ降りるので、橋と土手がつながって見える。下は石積みの橋台が支える。なめらか画質では中桟・筋交い・板目が増える
  - 橋のあるタイルは**通行できる**ようになる。隊商はここを渡って対岸のマップ端へ抜けられ、探訪モードの君主も歩いて渡れる
  - 川で市と目的の方角が分断されていると交易路は開けない。そのときは橋を架ければよい
- 古い国史(セーブ)は保存された当時の広さのまま復元される(64×64 の国はそのまま遊べる)

## ほのみモード (やさしい表示)

右下の「**ほのみ**」ボタンで切り替え。小学3年生でも読めるように、

- むずかしい言葉をやさしい言いかえにする(例: 婚姻→結婚、朝貢→みつぎ物、士気→やる気、併合→じぶんの国にする、苛政は虎よりも猛し→きびしい税はトラよりもこわい)
- むずかしい漢字にふりがなを付ける(内政(ないせい)・貨幣(かへい)・城壁(じょうへき)・覇者(はしゃ)など約150語)
- 文字を少し大きく、行間を広めにする

ログ・各パネル・民の声・バトル画面など、画面に出る文字が自動で変換される(MutationObserver による後付け変換なので、ゲーム本体の文章は書き換えていない)。設定はブラウザに保存され、もう一度押すと完全に元の表示へ戻る。

## 表示と教育 (Phase 3.5)

- **画質モード** — 右下の「画質」ボタンでローポリ ⇔ なめらかを切り替え。なめらかでは
  - 地形を4×4に細分しバイキュービック補間した連続的な起伏になり、色も隣のタイルへ滑らかににじむ
  - **波打ち際が白く**なり、水面も岸に近いほど明るい高精細版になる
  - 建物の屋根に**筒瓦の筋・棟瓦・軒先**が描き込まれ、宮殿などの瓦が精緻になる。壁や基壇は**面取り**されて角が柔らかくなり、柱は丸く、茅葺きの角錐屋根は丸屋根に、木々は二段重ねの樹冠になる。内部解像度も上がる
  - そのぶん描画は重くなる。軽くしたいときはローポリへ戻す。設定はブラウザに保存される
- **住民の表示** — 俯瞰(選択・撤去・建設)では住民は表示されない。「探訪」で街に降り立つと、民が家や職場のまわりに立っており、近づいて E で話しかけられる(歩き回りはしない)。民の生業・声のデータは内政パネルで引き続き見られる
- **教育水準** — 上部バー4段目。学問所(約60人ぶん)・官署(約12人ぶん)・宮殿が民に学びを授け、人口に対する割合で水準が決まる。内政パネルに詳細
- **建物グレード** — 教育40で普請が丁寧になり(木組み・整った茅葺き、住居+1、防衛+25%)、教育75で瓦葺きの家と磚(せん)積みの城壁に建て替わる(住居+2、防衛+50%)。里・里門・城壁・城門・望楼の見た目が変わり、教育が下がると元に戻る

## Phase 3 で確認できること

1. **国選択** — ゲーム開始時 (と「新しい天地」) に、史実の10カ国 (斉・晋・楚・秦・呉・越・魯・鄭・宋・燕) から自国を選ぶ。国ごとに国風 (特色) が違う:
   - 斉=貨幣収入+15%と**斉限定の「塩田」**(水辺に建てると貨幣を産む) / 秦=政策費-30%だが後進国で名声低め / 楚=木材豊富だが蛮夷扱いで名声低め / 魯=礼の国で民心と名声が高い、など
2. **他国AI** — 各国は毎年国力を伸ばし、AI同士で戦争する。戦国に入ると弱国は併合されて天下が狭まっていく。史実イベントも起こる:
   - **三家分晋**(戦国前期に晋が韓・魏・趙へ分裂。プレイヤーが晋なら防がれる)
   - **臥薪嘗胆**(紀元前473年ごろ越が呉を滅ぼす)、田氏代斉の風聞
3. **外交** — 「外交」ボタンで諸侯の一覧 (国力・関係・特産・通貨圏)。コマンド:
   - **贈物**(関係改善) / **同盟**(関係55以上。交易+20%・隊商の略奪半減) / **婚姻**(関係35以上で絆が深まる) / **朝貢**(格上の国に毎年貨幣40を納めて安全を買う)
   - **尊王**(周王室への献上で名声+10。戦国後期は形骸化して+4) / **会盟の主催**(名声60+貨幣300+あわ200+半数以上と中立以上 → **覇者**となり名声+40・民心+3)
   - 上部バーに**名声**が追加。名声が高いほど諸侯の態度の土台が良くなる
4. **他国からの要求** — 強く不機嫌な国が貢ぎ物を要求してくる。応じるか、はねつけるか (関係悪化と引き換えに名声+2)。周王室から祭祀のあわを求められることも
5. **貿易** — 外交パネルから「交易路を開く」(市1つにつき1本まで、貨幣60)。**牛車の隊商が市からマップ端 (相手国の方角) まで実際に3Dマップを旅する**。相手国に1季節滞在して戻り、貨幣と特産の持ち帰り品 (楚の青銅、燕の布など) をもたらす
   - 利益は相手の国力・特産・時代・関係・同盟で変わる。**通貨圏**(布銭/刀銭/蟻鼻銭/円銭) が同じなら+15%、違えば両替の手間で-10%
   - 帰路には**野盗の略奪リスク**(治安が低い・敵対国が多いと危険。同盟相手への路は安全)
6. **セーブv3** — 他国の生死・国力・関係・交易路もセーブされる。Phase 2 のセーブも読み込める (他国は初期状態から)

### Phase 3 の動作確認のしかた
1. 起動すると国選びの画面が出る。まずは**斉**か**鄭**(商業国) がわかりやすい
2. 「外交」を開き、どこか関係が中立以上の国に**贈物**を2〜3回 → 関係が友好まで上がったら**交易路を開く**
3. 画面を引いて眺めると、市から牛車の隊商がマップの端へ旅立つのが見える。数季節後「◯◯との交易で貨幣◯◯を得た」のログが出る
4. 貨幣が貯まったら**尊王の献上**を繰り返して名声を60まで上げ、**会盟を主催**して覇者になってみる
5. 4倍速で数十年回すと、AI国同士の戦争、戦国期の併合、三家分晋などのログが流れる

## Phase 2 で確認できること

1. **住民が街を歩く** — 人口ぶん(上限140体)の住民が3Dの街を実際に歩き回る。朝に家を出て職場へ行き、昼下がりに市へ寄り、夕方に帰宅する一日サイクル。衣の色で見分けられる: 農民=土色 / 職人=藍 / 士人=白 / 兵士=朱、**商人=男:深緑・女:若緑 / 町人=男:灰茶・女:小豆 / 子ども=男:山吹・女:桃**。子ども(人口の約2割)は体も小さく、働かずに家の周りや市で遊ぶ。水域は避けて歩き、遠景ではLODで間引き・非表示になる。
   - **顔と表情**: 住民は全員が髪・まげつきの頭と表情のある顔を持つ(遠近で見た目が変わる混在はない)。表情は6種(通常/微笑/満面/不満/険しい/疲労)で国の状態に連動 — 民心が高いと笑顔が増え、飢餓・俸給未払い・重税では不満顔、兵士は険しい顔。顔は CanvasTexture でコード生成した表情アトラス+インスタンスごとのUVオフセットで描く。
   - **民の声**: 選択モードで住民をクリックすると、名前・生業・住まい・働き先と、その民が**いま思っていること**が聞ける。声は税の軽重・食糧・住居不足・失業・治安・政策・季節・職業から生成されるので、民情のリサーチに使える。内政パネルにも無作為3人の「民の声」欄がある。
2. **城壁の自動接続** — 城壁を隣り合わせに置くと、自動で一続きの壁(直線・L字・T字・十字)につながる。城門にも接続する。ゴーストプレビューも接続後の形で表示。撤去すると隣の壁が作り直される。孤立した1枚だけのときは R キーの向きが効く。
3. **探訪モード** — 右下の「探訪」ボタンで君主として街に降り立ち、三人称視点で歩ける。
   - WASD で歩行(Shift で早歩き)、マウスドラッグで視点、ホイールで肩越し〜引きのズーム。水は渡れず、地形の起伏に沿って歩く。
   - 民に近づくと「E: 話しかける」が出て、**E かクリックで会話**。相手は立ち止まってこちらを向き、いま思っていることを話す(声の内容は民情と連動)。
   - Esc(または探訪ボタン)で上空の視点に戻る。探訪中もゲーム時間は流れ、建設操作だけ無効になる。
2. **税率** — 内政パネルのスライダーで薄税〜苛税の5段階。重いほど貨幣収入が増え民心が下がる。
3. **政策** — 初税畝(田の実収+12%)、鋳造貨幣(貨幣収入+25%)、鉄製農具(田+15%)、変法(徴税+15%・労働力+5%)。時代と前提建物・費用を満たすと布告できる。
4. **時代進行の条件化** — 年数だけでなく人口・建物・政策の達成で時代が進む。内政パネルに次の時代の要件チェックリスト(✓/・)が出る。
   - 春秋後期: 紀元前720年 + 人口60 + 市 + 宗廟 → 学問所・初税畝・鋳造貨幣が解放
   - 戦国前期: 紀元前560年 + 人口120 + 学問所 + 初税畝採用 → 鉄工房・鉄・変法が解放
   - 戦国後期: 紀元前430年 + 人口220 + 鉄工房 + 変法採用
5. **セーブ/ロード** — 書庫パネルに自動保存+手動3スロット。毎年オートセーブ。ロードすると同じシードから世界を再構築し、開墾済みの森・建物・資源・政策まで完全復元。「新しい天地」で新規マップ。
6. **新建物** — 学問所(春秋後期)、鉄工房(戦国前期、木材を食って鉄を産む)。ロック中の建物は建設メニューに「◯◯で解放」と表示。

## Phase 1 で確認できること

1. **地形** — マップを開くたびに 96×96 の地形が生成される。蛇行する大河(黄河)、東方の海と砂浜、丘陵、森林。ローポリ+頂点カラーで、外部画像は一切使っていない。
2. **カメラ** — 左ドラッグで真上から水平近くまで自由に回り込める。
3. **建設** — 下部メニューの5カテゴリ(統治・居住・生産・経済・防衛)から18種類。カーソルを地面に合わせると**半透明のゴースト**が出て、緑=建設可・赤=不可。理由(水域・急傾斜・森に隣接していない等)はログに出る。
4. **開墾** — 森のタイルに建てると木が消え、地面が平地の色に変わり、木材 +12 が入る。
5. **撤去** — 撤去モード、または情報パネルの「取り壊す」ボタン。費用の半額が戻る。
6. **資源と人口** — 粟・貨幣・木材・青銅・布帛 + 人口 / 労働力。上部バーの小さな数字は**今の季節あたりの増減**。
7. **時間進行** — 紀元前770年 春から開始。1季節=10秒(1倍速)。季節が変わると日射しと草木の色が変わり、粟は**秋に一気に実り冬は穫れない**。

### まず試すとよい流れ
1. 起動直後は宮殿・里・粟田・糧倉が建った「始まりの邑」。人口24、住居32。
2. **生産タブ → 粟田**を川沿い(肥沃度が高い)に数枚建てる。地面をクリックで情報パネルを開くと肥沃度と水辺までの距離が見える。
3. **経済タブ → 市/糧倉**、**生産タブ → 製陶窯**で貨幣収入を作る。窯は木材を食うので**木こり小屋**(森に隣接)も要る。
4. **居住タブ → 里**で住居を増やすと人口が増える。ただし人手(労働)より職(jobs)が多すぎると全施設の稼働率が下がるので、上部バーの「労働/職」を見ながら調整する。
5. 4倍速で数十年回すと、人口・民心・貯蔵上限のバランスが見えてくる。

## ゲーム内部の仕組み(Phase 1 時点)

- **労働力** = 人口 × 55%。全建物の必要人手の合計に対する比率が、そのまま全建物の稼働率になる(人手不足のペナルティ)。
- **季節係数** — 粟田は [春0.2 / 夏0.6 / 秋2.4 / 冬0.0]、桑畑は夏に強い、など。
- **材料の連鎖** — 青銅工房・製陶窯は木材を消費する。木材が足りなければ自動的に稼働が落ちる。
- **民心** — 食糧収支・住居の余り・失業率・治安・宮殿や宗廟の威信・俸禄の未払いから目標値を出し、季節ごとに25%ずつそこへ近づく。45未満で人口が増えなくなり、25未満で流民が出る。
- **貯蔵上限** — 粟は基本320、糧倉1つにつき+420。あふれたぶんは腐る。
- **流民の来訪** — 食糧と住居に余裕があれば他国から民が流れ込む。
- **時代** — 年+人口+建物+政策の全条件を満たした年に移行する(`js/config.js` の `ERAS[].req`)。
- **政策の効果** — `policyFx()` が採用済み政策を合成: 田系の産出倍率(初税畝×鉄製農具は乗算)、貨幣収入倍率、徴税効率、労働可能率、民心の恒常補正。
- **住民の一日** — `DAY_SECONDS`(9秒)を1日とし、個体ごとの位相ずらし付きで 家→職場→(市)→家 を巡回。経路は水域を避けるBFSで、建物ペア間の経路はキャッシュされる。倍速時も歩行は2倍まで(4倍速で瞬間移動に見えないように)。
