# 覇道 — 春秋戦国都市建設シミュレーション

Three.js によるブラウザゲーム。**現在 Phase 2 完了**(住民エージェント・税制と政策・時代進行の条件化・セーブ/ロード)。

## 動作確認のしかた

### いちばん簡単な方法
`index.html` をダブルクリックしてブラウザで開く。
Three.js はローカル同梱(`vendor/three.min.js`)なので、ネット接続もサーバも不要。

### 簡易サーバで開く場合
```
cd C:\Users\kazuh\sengoku-game
python -m http.server 8000
```
→ ブラウザで http://localhost:8000

推奨ブラウザ: Chrome / Edge / Firefox(WebGL が動くもの)

## Phase 2 で確認できること

1. **住民が街を歩く** — 人口ぶん(上限140体)の住民が3Dの街を実際に歩き回る。朝に家を出て職場へ行き、昼下がりに市へ寄り、夕方に帰宅する一日サイクル。衣の色で見分けられる: 農民=土色 / 職人=藍 / 士人=白 / 兵士=朱、**商人=男:深緑・女:若緑 / 町人=男:灰茶・女:小豆 / 子ども=男:山吹・女:桃**。子ども(人口の約2割)は体も小さく、働かずに家の周りや市で遊ぶ。水域は避けて歩き、遠景ではLODで間引き・非表示になる。
   - **顔と表情**: カメラを寄せる(ホイールでズームイン、目安は半径10以下)と、近くの住民(最大48人)が顔つきの頭に切り替わる。表情は6種(通常/微笑/満面/不満/険しい/疲労)で国の状態に連動 — 民心が高いと笑顔が増え、飢餓・俸給未払い・重税では不満顔、兵士は険しい顔。顔は CanvasTexture でコード生成した表情アトラス+インスタンスごとのUVオフセットで描く。
   - **民の声**: 選択モードで住民をクリックすると、名前・生業・住まい・働き先と、その民が**いま思っていること**が聞ける。声は税の軽重・食糧・住居不足・失業・治安・政策・季節・職業から生成されるので、民情のリサーチに使える。内政パネルにも無作為3人の「民の声」欄がある。
2. **城壁の自動接続** — 城壁を隣り合わせに置くと、自動で一続きの壁(直線・L字・T字・十字)につながる。城門にも接続する。ゴーストプレビューも接続後の形で表示。撤去すると隣の壁が作り直される。孤立した1枚だけのときは R キーの向きが効く。
3. **探訪モード** — 右下の「探訪」ボタンで君主として街に降り立ち、三人称視点で歩ける。
   - WASD で歩行(Shift で早歩き)、マウスドラッグで視点、ホイールで肩越し〜引きのズーム。水は渡れず、地形の起伏に沿って歩く。
   - 民に近づくと「E: 話しかける」が出て、**E かクリックで会話**。相手は立ち止まってこちらを向き、いま思っていることを話す(声の内容は民情と連動)。
   - Esc(または探訪ボタン)で上空の視点に戻る。探訪中もゲーム時間は流れ、建設操作だけ無効になる。
2. **税率** — 内政パネルのスライダーで薄税〜苛税の5段階。重いほど貨幣収入が増え民心が下がる。
3. **政策** — 初税畝(田の実収+12%)、鋳造貨幣(貨幣収入+25%)、鉄製農具(田+15%)、変法(徴税+15%・労働力+5%)。時代と前提建物・費用を満たすと布告できる。
4. **時代進行の条件化** — 年数だけでなく人口・建物・政策の達成で時代が進む。内政パネルに次の時代の要件チェックリスト(✓/・)が出る。
   - 春秋後期: 紀元前720年 + 人口60 + 市 + 宗廟 → 学問所・初税畝・鋳造貨幣が解放
   - 戦国前期: 紀元前560年 + 人口120 + 学問所 + 初税畝採用 → 鉄工房・鉄・変法が解放
   - 戦国後期: 紀元前430年 + 人口220 + 鉄工房 + 変法採用
5. **セーブ/ロード** — 書庫パネルに自動保存+手動3スロット。毎年オートセーブ。ロードすると同じシードから世界を再構築し、開墾済みの森・建物・資源・政策まで完全復元。「新しい天地」で新規マップ。
6. **新建物** — 学問所(春秋後期)、鉄工房(戦国前期、木材を食って鉄を産む)。ロック中の建物は建設メニューに「◯◯で解放」と表示。

## Phase 1 で確認できること

1. **地形** — マップを開くたびに 64×64 の地形が生成される。蛇行する大河(黄河)、東方の海と砂浜、丘陵、森林。ローポリ+頂点カラーで、外部画像は一切使っていない。
2. **カメラ** — 左ドラッグで真上から水平近くまで自由に回り込める。
3. **建設** — 下部メニューの5カテゴリ(統治・居住・生産・経済・防衛)から18種類。カーソルを地面に合わせると**半透明のゴースト**が出て、緑=建設可・赤=不可。理由(水域・急傾斜・森に隣接していない等)はログに出る。
4. **開墾** — 森のタイルに建てると木が消え、地面が平地の色に変わり、木材 +12 が入る。
5. **撤去** — 撤去モード、または情報パネルの「取り壊す」ボタン。費用の半額が戻る。
6. **資源と人口** — 粟・貨幣・木材・青銅・布帛 + 人口 / 労働力。上部バーの小さな数字は**今の季節あたりの増減**。
7. **時間進行** — 紀元前770年 春から開始。1季節=10秒(1倍速)。季節が変わると日射しと草木の色が変わり、粟は**秋に一気に実り冬は穫れない**。

### まず試すとよい流れ
1. 起動直後は宮殿・里・粟田・糧倉が建った「始まりの邑」。人口24、住居32。
2. **生産タブ → 粟田**を川沿い(肥沃度が高い)に数枚建てる。地面をクリックで情報パネルを開くと肥沃度と水辺までの距離が見える。
3. **経済タブ → 市/糧倉**、**生産タブ → 製陶窯**で貨幣収入を作る。窯は木材を食うので**木こり小屋**(森に隣接)も要る。
4. **居住タブ → 里**で住居を増やすと人口が増える。ただし人手(労働)より職(jobs)が多すぎると全施設の稼働率が下がるので、上部バーの「労働/職」を見ながら調整する。
5. 4倍速で数十年回すと、人口・民心・貯蔵上限のバランスが見えてくる。

## ゲーム内部の仕組み(Phase 1 時点)

- **労働力** = 人口 × 55%。全建物の必要人手の合計に対する比率が、そのまま全建物の稼働率になる(人手不足のペナルティ)。
- **季節係数** — 粟田は [春0.2 / 夏0.6 / 秋2.4 / 冬0.0]、桑畑は夏に強い、など。
- **材料の連鎖** — 青銅工房・製陶窯は木材を消費する。木材が足りなければ自動的に稼働が落ちる。
- **民心** — 食糧収支・住居の余り・失業率・治安・宮殿や宗廟の威信・俸禄の未払いから目標値を出し、季節ごとに25%ずつそこへ近づく。45未満で人口が増えなくなり、25未満で流民が出る。
- **貯蔵上限** — 粟は基本320、糧倉1つにつき+420。あふれたぶんは腐る。
- **流民の来訪** — 食糧と住居に余裕があれば他国から民が流れ込む。
- **時代** — 年+人口+建物+政策の全条件を満たした年に移行する(`js/config.js` の `ERAS[].req`)。
- **政策の効果** — `policyFx()` が採用済み政策を合成: 田系の産出倍率(初税畝×鉄製農具は乗算)、貨幣収入倍率、徴税効率、労働可能率、民心の恒常補正。
- **住民の一日** — `DAY_SECONDS`(9秒)を1日とし、個体ごとの位相ずらし付きで 家→職場→(市)→家 を巡回。経路は水域を避けるBFSで、建物ペア間の経路はキャッシュされる。倍速時も歩行は2倍まで(4倍速で瞬間移動に見えないように)。

## ファイル構成

```
index.html          画面レイアウト
css/style.css       UI スタイル
vendor/three.min.js Three.js r155 (ローカル同梱)
js/config.js        設定・資源・建物データ・バランス定数・配色
js/rng.js           シード付き乱数とバリューノイズ
js/terrain.js       地形生成 / 地形・水面・木のメッシュ化
js/meshes.js        建物ジオメトリの生成(箱・円錐・切妻屋根を合成)
js/controls.js      自作オービットカメラ
js/city.js          グリッド管理・建設可否判定・設置/撤去・開墾記録
js/state.js         資源・人口・民心・税制/政策・時代条件・季節精算
js/agents.js        住民エージェント (配役・BFS経路・一日サイクル・LOD)
js/save.js          セーブ/ロード (localStorage 4スロット)
js/ui.js            資源バー・建設メニュー・情報/内政/書庫パネル・ログ
js/main.js          シーン構築・世界の再構築・レイキャスト・ゲームループ
```

デバッグ用に `js/config.js` の `SEED` に 0 以外を入れると、同じ地形を再現できる。
